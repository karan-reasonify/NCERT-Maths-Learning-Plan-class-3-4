## 2. Learning objectives the book is aiming at
1. Name cube, cuboid, cylinder, cone and sphere, from objects and pictures.
2. Match everyday objects (classroom things, toys, the game pictures) to these shapes.
3. Point to and name a face, an edge and a corner of a solid.
4. Tell flat faces from curved faces, straight edges from curved edges; name the shapes that fit a description ("no edges", "only flat faces" ...).
5. Identify and count the shapes used in a model (rocket, toy engine, toys, houses, stacked models).
6. Use position words (between, on the top of, under, on) to say where a shape is.
7. Build houses, towers and rockets from shapes, and describe the order of building so others can build the same.
8. Compare shapes and say how they are the same and different; say that a cube is a special cuboid.
9. Make shapes with clay and sticks and with cubes; count the cubes in a shape.
10. Read the opposite faces of a die and describe the pattern.
11. Play the shape game and name the shape on a picture card.
