# Approved tool map: Class 3 Ch 1, What's in a Name?

Source: the content team's learning-plan note for this chapter (pasted by the user on 6 Nov 2026), rows 1 to 20, unchanged in names, purposes and order. Tool names are the note's own tool headings. Durations are written "45 to 55 s". The original text with its dashes is kept verbatim in lp_brief.md.

| # | Topic | Format / Tool | Purpose / learning focus | Placement in the note |

| 1 | Topic 1: The Cows of Tarakeshwar | Hook video | Introduce Deba and Deep taking cows out and bringing them home. They wonder how to know whether any cow is missing. End with the problem, without giving the answer. | Module 1, 45 to 55 s |
| 2 | Topic 1: The Cows of Tarakeshwar | Tool 1: Marks at the Gate | Students make one mark for each cow that leaves and strike out one mark for each cow that returns. Include the textbook question: "Did all the cows come back home?" | Module 1 |
| 3 | Topic 2: Marks Left on the Wall | Concept video | Explain what a standing mark and a struck-out mark mean. Show how groups of five make a large number of marks easier to read. | Module 1, 35 to 45 s |
| 4 | Topic 2: Marks Left on the Wall | Tool 2: Count the Big Herd | Use the exact textbook tally: nine groups of five and two extra marks = 47 cows. Students identify why Deba and Deep were worried, how many cows were still out (2), and how many reached home (45). | Module 1 |
| 5 | Topic 2: Marks Left on the Wall | Bridge image/video | Introduce Hemant's separate records. Explain that cows and sheep must be recorded in two different rows. This prepares students for the next tool. | Module 1, 20 to 30 s |
| 6 | Topic 2: Marks Left on the Wall | Tool 3: Hemant's Cows and Sheep | Students make separate tally records for 36 cows and 23 sheep. Do not combine the two totals. | Module 1 |
| 7 | Topic 3: How Long Is a Name? | Concept video | Use the textbook animal names to explain that name length means the number of letters, not the visual width of the word. | Module 2, 35 to 45 s |
| 8 | Topic 3: How Long Is a Name? | Tool 4: Longest and Shortest Names | One focused activity with three short stages: animal team captains; compare Mahesh and Kartik; compare the names students enter for the friends' name activity. Cover the related textbook questions without adding new questions. | Module 2 |
| 9 | Topic 4: Starting and Ending Letters | Concept image | Name Tags in a Row: show name tags with the first letter highlighted in orange and the last letter in blue. This image introduces the idea before the sorting activity. | Module 2 |
| 10 | Topic 4: Starting and Ending Letters | Tool 5: Starting and Ending Letters | Students identify their own starting letter, sort the textbook name set by starting and ending letters, count matching names, find the most-used starting letter and identify letters not used at the start. | Module 2 |
| 11 | Topic 5: Number Names | Concept video | Teji and Jojo build number names with cards. Show the tens card first, then the ones card; numbers 1 to 19 use one card. Explain that a hyphen is not a letter. | Module 2, 40 to 50 s |
| 12 | Topic 5: Number Names | Tool 6: Build a Number Name | Cover the textbook examples 43 and 17, then let students use their own roll number. The notebook task to write more number names is shown as a short optional instruction card, not a separate tool. | Module 2 |
| 13 | Topic 6: Number Puzzles and Place Names | Concept video | Teji and Jojo compare Twenty and Thirty and notice that different numbers can have the same number of letters. Introduce the eight-letter number-name puzzle. | Module 2, 35 to 45 s |
| 14 | Topic 6: Number Puzzles and Place Names | Tool 7: Number Name Puzzles | Cover the textbook tasks: numbers with eight letters, longest number names, the near-100 clue and the smallest name from 63 to 78. Accept all valid answers: 93, 97 and 98 for the near-100 clue; 70 for the 63 to 78 clue. Show a short instruction card for making a similar puzzle in the notebook. | Module 2 |
| 15 | Topic 6: Number Puzzles and Place Names | Concept image | Longest and Shortest Place Names: show Venkatanarasimharajuvaripeta, Ib and Od on clear signboards. Spell all names exactly using digitally typeset text. | Module 2 |
| 16 | Topic 7: Grouping Things | Story video | Teji groups picture cards by a rule. Jojo arranges the same cards differently. Do not reveal Jojo's rule; let students discover it in the tool. | Module 3, 40 to 50 s |
| 17 | Topic 7: Grouping Things | Tool 8: Group the Cards Two Ways | One tool focused on grouping by a rule, with three short stages: identify Jojo's rule (things that fly / do not fly); sort the eight household objects by electricity use; regroup the same eight objects using another valid rule. Accept multiple sensible groupings in the final stage. | Module 3 |
| 18 | Topic 7: Grouping Things | Concept image | Hair Styles in a Class: use the textbook practice-class image with exactly 12 clearly visible children and six distinguishable hairstyles. Students observe the image and count each hairstyle using the textbook table. No separate tool is needed. | Module 3 |
| 19 | Topic 8: Chapter Review | Review | Review visual 1, Marks and Names: quick visual recap of standing and struck marks, longest and shortest names, starting and ending letters and place-name comparison. | Module 4 |
| 20 | Topic 8: Chapter Review | Review | Review visual 2, Number Names and Groups: quick visual recap of number cards, same letter counts, grouping by a rule and hairstyle groups. Reuse existing chapter visuals; no new tool or extra question set. | Module 4 |

Developer flow rules (from the note): keep the original four modules and eight topics; do not create extra topics for every small step; never place two tools directly one after another, use the listed video or image transition between them; each tool focuses on one learning concept and keeps several textbook questions together only when they practise the same concept; videos are short and story-led (most 35 to 55 s, the Hemant bridge 20 to 30 s); every concept has a relevant visual (the tool's main scene for tool-led concepts, a dedicated image or video for concepts without a tool).
