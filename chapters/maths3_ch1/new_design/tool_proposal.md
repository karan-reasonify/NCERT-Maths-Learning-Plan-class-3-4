# Tool proposal: Class 3, Chapter 1, "What's in a Name?"

PROPOSED by the pipeline on the user's instruction (no content-team table existed); the user approves it at the structure stop. The table itself is `tool_map.md`. Nothing is locked, built or uploaded. The older live plan was not used: only the names of its tools were looked at, so that none of mine repeats them.

## 1. The proposal in one line

Hook video, Tool 1 (exploration), concept video, Tool 2, concept video, Tool 3, image, Tool 4, concept video, Tool 5, puzzle story video, Tool 6, image, concept video, Tool 7, image, review.

7 tools, 5 concept videos (one of them the brief's puzzle video, told as a story), 3 images, 1 hook, 1 review. The sequence is the book's own order: marks, names, number names, groups.

## 2. The 12 concepts: tool, image or video

| Concept | What it gets | Why |
|---|---|---|
| C1 A mark for each animal | hook, then Tool 1; named in concept video 1 | It is the book's own activity (a mark for each cow out, strike one out for each cow in). Doing it is the idea: the child finds that one mark for one cow tells whether any cow is missing. |
| C2 Reading the marks | concept video 1, then Tool 2 | Striking out until two marks are left is what makes "the marks left are the cows still out" real (M_MARK_2). Watching the story is not enough. |
| C3 Marks for two kinds | the second part of Tool 2 | The book's only task is to make marks for 36 cows and 23 sheep. It is the same skill as C1 and C2, and the book ties C1 to C3 in one Teacher's Note ("count large groups without numbers"), so it has no tool, video or image of its own. |
| C4 Length of a name is its letter count | concept video 2, then Tool 3 | Counting the letters of each name and comparing is the whole idea (and Mahesh and Kartik show two names can tie). The child must do the counting to avoid "the wider name is longer" (M_NAME_1). |
| C5 Starting and ending letters | image, then Tool 4 | Five questions that need names sorted by first or last letter. Piles make "most used" and "letters that start no name" visible. The idea is small, so an image sets the two words and no video is used. |
| C6 Number names and their letter count | concept video 3, then Tool 5 | Laying a tens card then a ones card (Forty, Three) is the book's own doing, and it fixes the order and the spelling traps (M_NUM_3, M_NUM_4, M_NUM_5). |
| C7 Same letter count (the 8 letter hunt) | puzzle story video 4, then Tool 6 | An investigation: try numbers, collect the 8 letter names, notice what they share. Needs trying many numbers, so it needs a tool. |
| C8 Longest number name, riddles, own puzzles | the same video and Tool 6 | The same hunt with other clues (the longest name, "6 letters then 5", "63 to 78"). A second tool would repeat the hunt, so C7 and C8 share one. |
| C9 Longest and shortest place names | image only | Two facts with photographs; the book asks nothing. A tool would be decoration. |
| C10 Group things by a rule | concept video 5, then Tool 7 | Dragging cards into two groups is the book's own doing (food, electricity). |
| C11 Another way to group the same things | the second round of Tool 7 | The book pairs it with C10 (Teacher's Note 4 names both). Finding Jojo's rule and regrouping the same cards is the same drag, so no second tool. |
| C12 Hair styles | image only (the book's question sits on it) | A look-and-count task on the child's own class. A tool would only repeat the sorting of Tool 7 with made-up data. Option in section 5. |

Concepts with no tool of their own: C3 (inside Tool 2), C8 (inside Tool 6), C11 (inside Tool 7), C9 and C12 (an image each). C1 has Tool 1 but no concept video of its own.

## 4. Why these 7 are not repeats of each other

- Tool 1 and Tool 2: make marks one for one (a few cows, no numbers) against read and keep marks for a big herd (47 marks, count what is left, two kinds apart).
- Tool 3 and Tool 4: both use names, but Tool 3 counts all the letters (how long) and Tool 4 looks only at the first and the last letter (how names are piled).
- Tool 5 and Tool 6: build a name from a number, against find the numbers from clues about their names (the back-to-front step).
- Tool 4 and Tool 7: piles by a letter against groups by a rule the child finds or chooses.
- Every tool follows a different kind of object: marks, names, name tags, number cards, a number hunt, picture cards.

## 5. Alternatives I considered and rejected

1. One tool for every concept (10 to 12 tools): rejected. It repeats the same drag, tap and count and adds a video or image for each tool, because every tool after Tool 1 must follow one.
2. A separate tool for Hemant (C3): rejected. It repeats the mark-making of Tool 1 without a new learning reason. Cost of my choice: Tool 2 is two parts (read, then make), and tapping 47 or 59 marks could be long, so the spec must allow a short path (a group of five at once). If the user wants it split, add an image and Tool 3 and number the rest again.
3. C7 and C8 as two tools: rejected (same hunt twice). C7 on Tool 5: rejected (building is not searching).
4. C10 and C11 as two tools: rejected (same drag). Tool 7 has two rounds.
5. C5 with no tool (image only, five questions on the image): the fallback if the user wants fewer. Tool 4 is the weakest of my seven.
6. C12 as its own tool or as a third round of Tool 7: the fallback if the user wants more doing. It would need a concept for C12 placed in Tool 7's unit and letus10 moved onto Tool 7 (then 4 questions).
7. A tool for C9: rejected (no question, nothing to do).
8. A tool for the roll number (letus4a) or the notebook tasks alone: rejected, they are questions of Tool 5.

## 6. Where the brief and the flow rules pull apart (and how I expressed it)

- Puzzle or activity videos (brief D): the pipeline has only a hook video and concept videos. The puzzles (the 8 letter hunt, the riddles) are a concept video told as a story (Teji and Jojo challenge each other, row 11), and the puzzle is solved on Tool 6.
- Chapter revision with concept checks and application questions (brief E): the review has no tool and no book item, so it has no place for a checked question. It can only recap what was taught. The visual recap can use the pinned images. A short check with the plan's own numbers has no slot; I did not invent one.
- "A tool for every meaningful objective" against the flow: every tool after Tool 1 needs a concept video or image before it, so each extra tool costs a media item. That is why I counted this cost in section 5.
- Phase 1 of a tool (reconnect with the preceding video): Tool 1 follows the hook, which teaches nothing, so its Phase 1 reconnects with the situation (the cows and the gate), not with a concept.
- Phase 3 (the exact book question on the tool): Tool 1 holds only story2, and C9 and the hook hold none (the brief says do not invent one).
- The teacher's role: the four Teacher's Notes are given to the child as ideas (for example, tnote1 as the closing line of video 1). They are not tools or questions.
- Brief item "do not introduce concepts assigned to later tools": video 1 must not teach number names; video 5 must not give away Jojo's rule (jojo1 asks it on Tool 7); video 2 must not give the answer of letus2.
- The brief wants a tool for the chapter's hands-on tasks; several of the book's hands-on tasks need the child's own data (friends, roll number, class), which a tool cannot hold. See open question 5.
